Créer l'espace privé

Une galerie à part, chiffrée sur le Mac, qui ne s'ouvre qu'avec ce code, sur chaque appareil (le Mac compris). Code oublié : les images privées sont perdues.

Espace privé

Changer le code privé

Les images privées sont rechiffrées avec de nouvelles clés et restent lisibles avec le nouveau code ; une ancienne copie de l'espace ne s'ouvre plus avec l'ancien. L'espace se ferme sur tous les appareils.

Espace privé

L'espace privé ne s'ouvre qu'en HTTPS ou sur le Mac lui-même : par cette adresse en http://, le code et les images passeraient en clair sur le Wi-Fi.

Ouvrez l'application par son adresse HTTPS (Tailscale), celle qui commence par https:// dans « Ouvrir depuis le téléphone », sur le Mac (lampe d'état, en haut à droite).

Supprimer l'espace privé

Toutes les images privées seront effacées définitivement, sans pouvoir être récupérées. Utile si le code est oublié ; un nouvel espace pourra être créé ensuite.

Sans le code, l'espace privé ne se supprime que sur le Mac lui-même, pour qu'un autre appareil ne puisse pas l'effacer : ouvrez l'application sur le Mac.
